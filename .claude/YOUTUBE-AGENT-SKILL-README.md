# YouTube Agent Skill Pack

Project-local installation of `Jakeschincariol/youtube-agent-skill` at commit
`a2feb2104981a375ffd4f87ee04f4f5344ac43c6` (MIT).

Installed commands: `/yt-audit`, `/yt-chapters`, `/yt-comment`, `/yt-edit`,
`/yt-package`, `/yt-plan`, `/yt-retention`, `/yt-script`, `/yt-seo`,
`/yt-shorts`, and `/yt-viral`.

The pack is intentionally offline and does not publish. Its six bundled Python
helpers use the standard library only. To personalize generated copy later,
follow the upstream optional voice-profile setup in `templates/voice.md`:
copy it to `~/.claude/youtube/voice.md` and complete it with the creator's own
voice, audience, and claim boundaries.

Upstream: https://github.com/Jakeschincariol/youtube-agent-skill
